# Reva Daily — Preferences & Ranking Rubric

This file is read at the start of every daily run and updated after feedback conversations. Keep it current — don't let it grow unbounded; compress old entries into the "Current preferences" summary periodically.

## Ranking rubric (defaults — adjust below as feedback comes in)

- **Long-form pick (1 per category)**: the most consequential development of the day, judged by how many independent reputable outlets are converging on the same story/theme. Prefer analysis/explainer/op-ed over spot news. Regulation/policy angle is a plus, not a requirement.
  - **Recency requirement**: the piece itself must be published within the last 48 hours. Check and show its publish date in the digest. If the most important underlying event is older but still actively developing (new reactions, new reporting, follow-on consequences), pick coverage of the latest development rather than the original older piece — don't let a stale (5+ day old) article lead just because it feels significant.
- **Roundup (max 5 per category)**: prioritize cross-source corroboration, recency, and topic diversity — don't run multiple items on the same underlying story. Each item: 50-60 words, cites the primary outlet(s) reporting it for further reading. Regulation/policy relevance gets a boost.
  - **Source diversity requirement**: cite primary/named reporting (e.g. Reuters, AP, BBC, FT, Axios, Politico, Semafor, or the specific outlet that broke/covered the story) — not a single aggregator digest (e.g. a daily "intelligence brief" newsletter) as the citation for multiple items. Aggregators are fine as a lead to *find* stories, but trace each one to its primary source before citing. No more than one of the five roundup items per category should share the same single source domain, unless that outlet is genuinely the only one covering it.
- **X takes (max 5, Tech/AI only)**: reactions/hot-takes/analysis from named individuals in the ecosystem — researchers, journalists, practitioners — not corporate/brand accounts, and not tweets that just restate a fact already in the roundup. Each tweet must add a new angle, opinion, or supplementary detail beyond what's already summarized elsewhere in the digest. Humor/wit is a plus. Pulled from ones already embedded/quoted within the newsletters and articles used for the other sections — not live X search. Snippet + link. If nothing genuinely clears this bar, ship fewer than 5 (including zero) rather than padding with weak or duplicate-fact tweets.
- **Paper pick (1, Tech/AI only)**: prioritize clear policy/governance implications over pure technical novelty.
- **Extended section**: only include when the day's candidate pool clearly exceeds the roundup cap (a major event, unusually many strong long-form pieces). List extra items with a one-line description + link, no strict cap.
- **Rationale**: each category's roundup ends with a short note on why these particular stories were chosen and why they matter.
- **Reading list (added 2026-10-17, daily, after both categories and before the feedback questions)**: 8-10 articles scoured from the web that are worth reading beyond what's already in the digest. Roughly 4-5 Tech/AI, 4-5 Geopolitics, plus up to 2 "wildcard" deep cuts (science, economics, culture, or a longer essay) if something strong turns up. Each entry: title, outlet/author, link, publish date, an estimated read time if the page states one, a "paywalled" flag if known, and one line (max ~25 words) on why it's worth the time. Must not duplicate the long-form pick or any roundup item. Prefer pieces from the last 7 days, but an older evergreen essay is fine if it sharpens a current story (label it as older). Use only URLs that actually appeared in search results or fetches this run; never construct or guess a link. Favor analysis, explainers, and primary documents over spot news. Distinct from the Extended section, which is overflow on unusually busy days.
